# Project process records

This folder records how the project was planned, built and verified.

- [`planning/planification.md`](planning/planification.md): the original implementation plan (backlog by phase, task IDs, traceability table, open questions).
- [`decisions.md`](decisions.md): decisions taken while implementing, and where the work differs from the plan.
- [`verification.md`](verification.md): what was checked in each phase, how, and what was **not** verified.

Nothing here is a formal code review. Review evidence is the test suite, CI and the manual checks listed in `verification.md`.
